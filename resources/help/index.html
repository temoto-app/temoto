はじめにGetting Started

{{app.name}} は、あなたが入れてログインしたエージェント CLI ({{backend.primary}}、または {{backend.secondary}}) を子プロセスとして動かす macOS のデスクトップアプリです。 CLI は同梱も改変もしません。スレッドごとの会話、承認の受け箱、Mac 全体のファイルの索引と検索、ファイルのビューアを 1 つの窓にまとめます。

画面の構成

  • 左端のアイコンバー: 上から「新しいスレッド」、スレッド・ファイル・検索・定期実行・拡張機能などの切り替え、最下段にこのヘルプ (?) と設定 (歯車)。同じアイコンをもう一度押すとサイドバーを畳みます (⌘B でも)。
  • サイドバー: スレッドの一覧 (作業フォルダごと)、ファイルのツリー、検索の結果など。
  • 中央: 選んだスレッドの会話と、その下のプロンプト欄。
  • 右のビューア: ファイル・差分・Web ページ・このヘルプを表示します。
  • 画面下のバー: git のブランチや差分の件数、使用量の上限の札、版の札など。

最初の会話

  1. エージェント CLI を入れてログインしておきます ({{app.name}} は CLI の認証情報を読みません。サブスクリプションのログインでも API キーでも使えます)。
  2. アイコンバーの最上段の「新しいスレッド」(⌘⇧O) を押し、作業するフォルダを選びます。バックエンド ({{backend.primary}} / {{backend.secondary}}) もここで選べます。
  3. プロンプト欄に頼みたいことを書き、Enter で送ります。

スレッドの一覧には、未読・実行中・承認待ちの件数・最終更新時刻が出ます。いくつかの会話を同時に走らせ、承認待ちを見落とさずに行き来できます。 長く動きのない会話は「さらに表示」に畳まれます (日数は設定で変えられます)。

ターミナルや VS Code で始めた会話を {{app.name}} で続けることも、その逆もできます。

{{app.name}} is a macOS desktop app that runs the agent CLI you installed and logged in to ({{backend.primary}}, or {{backend.secondary}}) as a child process. It does not bundle or modify the CLI. It puts per-thread conversations, an inbox for approvals, an index and search of the files on your Mac, and file viewers into one window.

The window

  • Activity Bar (left edge): “New Thread” at the top, then the modes (Threads, Files, Search, Schedule, Extensions and so on), and at the bottom this Help (?) and Settings (gear). Clicking the current mode again collapses the sidebar (⌘B does the same).
  • Sidebar: the thread list (grouped by working folder), the file tree, search results and so on.
  • Center: the conversation of the selected thread, with the prompt box below it.
  • Viewer (right): shows files, diffs, web pages and this Help.
  • Bottom bar: the git branch and change counts, the usage-limit badge, the version badge and so on.

Your first conversation

  1. Install the agent CLI and log in. ({{app.name}} never reads the CLI’s credentials. Both a subscription login and an API key work.)
  2. Click “New Thread” at the top of the Activity Bar (⌘⇧O) and choose the folder to work in. You can also choose the backend ({{backend.primary}} / {{backend.secondary}}) there.
  3. Type what you want in the prompt box and press Enter.

The thread list shows unread threads, running threads, the number of pending approvals and when each thread last changed, so you can run several conversations at once without missing an approval. Threads that have been inactive for a while are folded under “Show more” (the number of days is a setting).

A conversation started in a terminal or in VS Code can be continued in {{app.name}}, and the other way round.

プロンプトPrompt

  • Enter で送信、⇧Enter で改行。日本語の変換を確定する Enter では送りません。
  • 回答の途中で Enter を押すと、次に送る発言として予約します。今の回答を止めてすぐ送るのは ⌘Enter。
  • @ でファイルを指定できます (候補が出ます)。
  • ! で始めると、その行をシェルのコマンドとして 1 回実行します ({{app.name}} にはターミナルの画面はありません)。
  • / で始めると、/compact /clear /context /model /mcp /usage などの CLI のコマンドと、登録されている skill が補完に出ます。 対話画面専用のコマンド (/status /help /memory など) は CLI の非対話モードでは動きません。
  • Plan: ⇧Tab (またはプロンプト欄の札) で ON / OFF。ON の間、モデルは調べて計画だけを出し、計画を見てから進めるかを選びます。
  • プロンプト欄の下で、このスレッドの Model と Thinking を替えられます。
  • マイクのボタン、または入力欄にカーソルがあるときの ⌘D で音声入力ができます (macOS の音声認識。音声も文字起こしも保存しません)。
  • プロンプト欄のドーナツはコンテキストの使用量です。押すと内訳が出て、そこから /compact もできます。

回答の中のファイルのパスと URL はリンクになり、押すとビューアや Web 表示で開きます。

  • Enter sends, ⇧Enter inserts a new line. The Enter that confirms an IME conversion does not send.
  • Pressing Enter while an answer is still running queues the message as the next one. ⌘Enter stops the current answer and sends right away.
  • Type @ to mention a file (suggestions appear).
  • A line that starts with ! runs once as a shell command ({{app.name}} has no terminal screen).
  • Type / for CLI commands such as /compact /clear /context /model /mcp /usage, and for your installed skills. Commands that only work in the interactive screen (/status /help /memory and so on) do not work in the CLI’s non-interactive mode.
  • Plan: turn it on or off with ⇧Tab (or the badge in the prompt box). While it is on, the model only investigates and writes a plan, and you choose whether to go ahead after reading it.
  • Below the prompt box you can change this thread’s Model and Thinking.
  • The microphone button, or ⌘D while the prompt box has the cursor, is voice input (macOS speech recognition; neither the audio nor the transcript is stored).
  • The donut in the prompt box is the context usage. Click it for the breakdown, and run /compact from there.

File paths and URLs in answers are links: clicking one opens it in the viewer or the built-in web view.

ファイルの添付File Attachments

  • ファイルや画像をドラッグ & ドロップするか貼り付けると添付できます。プロンプト欄と送った後の発言にサムネイルが出て、押すとビューアで大きく見られます。
  • 会話の画面に落とすときは、左半分が「添付」、右半分が「ビューアで開く」です。
  • プロンプト欄の 📷 (⌃⇧⌘5) で、{{app.name}} の窓を隠して画面の一部を撮り、そのまま添付できます。新しいスクリーンショットができたときは、プロンプト欄の上に添付の候補が出ます (設定の「入力」で止められます)。
  • ビューアで選んだ範囲は、次の発言に添えて送られます (VS Code 拡張と同じ動き)。
  • @ でファイルを名前で指定することもできます。

添付の本文や画像は、表示と送信のために使うだけで、{{app.name}} の索引には入れません。

  • Drag and drop or paste files and images to attach them. A thumbnail appears in the prompt box and in the sent message; click it to see it large in the viewer.
  • When you drop onto the conversation, the left half means “attach” and the right half means “open in the viewer”.
  • The 📷 button in the prompt box (⌃⇧⌘5) hides the {{app.name}} window, lets you capture part of the screen and attaches it. When a new screenshot appears, {{app.name}} offers it above the prompt box (you can turn this off under Settings > Input).
  • The selection in the viewer is sent along with your next message (the same as in the VS Code extension).
  • You can also mention a file by name with @.

Attached text and images are only used to show and send them; {{app.name}} does not add them to its index.

ビューアViewer

右のビューアは、ファイルの種類ごとの拡張機能で表示します: テキスト・Markdown・画像・PDF・動画・音声・Word / Excel (読み取り専用)・HTML・差分・zip など。 拡張機能は隔離された環境で動き、ファイルには {{app.name}} の許可の窓口を通してしか届きません。

  • 表示中のファイルはスレッドごとに覚えていて、スレッドを替えると戻ります。
  • ビューアの ← → (⌃- / ⌃⇧-) で前に見ていたファイルへ戻れます。タイトルバーの ← → (⌘[ / ⌘]) は、前に見ていたスレッドへ戻ります (サイドバーのモードはそのまま)。ファイルの見出しの ← → は、そのスレッドでファイルのツリーで選んだ項目を戻ります (ビューアは替えません)。
  • ✕ でビューアを閉じます。ヘルプや差分のような一時的な表示は、✕ (または ← / ⌘W) で閉じると、その前に見ていたファイルに戻ります。
  • Markdown と HTML は見出しで Preview / Source を切り替えます。編集したときだけ保存ボタンが出ます (⌘S)。自動保存は設定の「ファイルの表示」で選べます (既定は off)。
  • 別のビューアで開き直す (「Reopen With…」) と、拡張子ごとに覚えます。
  • HTML の Preview は、その HTML の中だけを描き、外部や他のファイルは読み込みません (script も動きません)。ページの中の #… のリンクだけが働きます。
  • ⌘T で空のビューアを出し、アドレス欄に URL やファイルのパス (main.ts:42 のような行付きも) を打って開けます。
  • 回答の中の http(s) のリンクは、アプリ内の Web 表示 (タブ・URL 欄・履歴・お気に入り) で開きます。
  • コードでは、同じ語の強調・⌘D と複数カーソル・折り畳み・記号の一覧 (⌘R)・宣言へ (F12)・代入と使用の一覧 (⇧F12) が使えます (開いているファイルの中だけ)。LSP・補完・診断はありません。込み入った編集は外部エディタで。

The viewer on the right shows files through Extensions, one per kind of file: text, Markdown, images, PDF, video, audio, Word / Excel (read-only), HTML, diffs, zip and more. Extensions run isolated and reach files only through {{app.name}}’s permission broker.

  • The file you were viewing is remembered per thread and comes back when you switch threads.
  • The viewer’s ← → (⌃- / ⌃⇧-) go back to files you viewed before. The ← → in the title bar (⌘[ / ⌘]) go back to threads you viewed before (the sidebar mode stays). The ← → in the Files heading go back to items you picked in the Files tree for that thread (the viewer does not change).
  • ✕ closes the viewer. Temporary views such as this Help or a diff go back to the file you were viewing when you close them with ✕ (or ← / ⌘W).
  • Markdown and HTML switch between Preview and Source in the header. The Save button appears only when there are edits (⌘S). Auto save is under Settings > File Viewer (off by default).
  • Reopening a file with another viewer (“Reopen With…”) is remembered per file extension.
  • The HTML Preview draws only that HTML file and loads nothing from outside or from other files (scripts do not run). Only links inside the page (#…) work.
  • ⌘T opens an empty viewer; type a URL or a file path (with a line, such as main.ts:42) into the address bar.
  • http(s) links in answers open in the built-in web view (tabs, URL bar, history, favorites).
  • In code: highlighting of the same word, ⌘D and multiple cursors, folding, the symbol list (⌘R), go to declaration (F12) and the list of assignments and uses (⇧F12), within the open file only. There is no LSP, completion or diagnostics; use an external editor for heavy editing.

承認と確認Permissions

{{app.name}} は確認のダイアログをなるべく出さず、自動で進める方針です。既定ではツールの実行は聞かずに通し、止まるのは次のときだけです。

  • AI からの質問 (選択式の質問は、その場で選んで答えます)。
  • 自分で Plan を ON にしたときの計画の提示。
  • 外へ送る操作 (メールや Slack への投稿、git push など)。全部を自動で通す既定でも必ず確かめます。
  • 設定の停止パターンに当たるシェルのコマンドと、厳格モードのスレッド (スレッドの ⋯ メニューで切り替え)。

承認待ちは、そのスレッドのプロンプト欄の上に出ます。別のスレッドの承認待ちも一覧の行に残り、アイコンバーやデスクトップ通知でも分かります。 長く放置しても打ち切られません。

  • 許可 / 拒否: その 1 回だけ。
  • Always allow: 以後同じ要求を聞かない規則を作ります。作った規則は 設定 > 承認 > Always allowed で外せます。

設定 > 承認

  • できるだけ確認しない (既定 ON) / 確認せずに通すツール / シェルの停止パターン / 聞かない接続先。
  • 全委任モード: 上の設定でもまだ聞く承認 (外へ送る操作など) も聞かずに通します。OS サンドボックスと一緒に使うことを勧めます。
  • CLI 自身の設定の許可リスト (permissions.allow) にあるものは CLI の中で通り、{{app.name}} の承認には届きません。

スレッドの ⋯ メニューの「OS サンドボックス」で、そのスレッドのコマンドを OS のサンドボックスの中で動かせます (接続先と書ける場所の許可表は設定の「承認」)。

{{app.name}} is designed to show as few confirmation dialogs as possible and to keep going on its own. By default tool calls pass without asking; work only stops for:

  • Questions from the AI (multiple-choice questions are answered right there).
  • The plan, when you turned Plan on yourself.
  • Actions that send things out (posting an e-mail or to Slack, git push and so on). These are always confirmed, even with the allow-everything default.
  • Shell commands that match a stop pattern in Settings, and threads in strict mode (toggle it in the thread’s ⋯ menu).

A pending approval appears above the prompt box of its thread. Approvals of other threads stay visible on their rows in the thread list, in the Activity Bar and as desktop notifications. They do not time out while you are away.

  • Allow / Deny: this time only.
  • Always allow: creates a rule so the same request is not asked again. Remove rules under Settings > Approvals > Always Allowed.

Settings > Approvals

  • Ask As Little As Possible (on by default) / Tools Allowed Without Asking / Shell Stop Patterns / Hosts Without Asking.
  • Full delegation: also allows, without asking, the approvals the settings above still ask for (such as sending things out). Using it together with the OS sandbox is recommended.
  • Anything allowed by the CLI’s own settings (permissions.allow) passes inside the CLI and never reaches {{app.name}}’s approvals.

“OS Sandbox” in the thread’s ⋯ menu runs that thread’s commands inside the OS sandbox (the allowed hosts and writable paths are under Settings > Approvals).

AI の設定AI Configuration

エージェント CLI

{{app.name}} が動かす CLI は 2 つです。どちらも {{app.name}} は同梱せず、あなたが入れたものを使います。入っているか・版・ログインの状態は、設定の「情報」のエージェント CLI の欄に出ます。

  • {{backend.primary}}: ログインの方法 (サブスクリプション / API キー) は CLI のまま。{{app.name}} は CLI の認証情報を読みません。
  • {{backend.secondary}}: {{backend.secondaryInstall}} で入れます。無料のモデルや Ollama のローカルモデル (ollama pull gpt-oss:20b) が使えます。thinking の段階・巻き戻し・画像の入力など、一部の機能は使えません。

どちらで動かすかは、新しいスレッドを作るときに選びます。

モデルと Thinking

新しいスレッドの初期値は 設定 > 新規スレッド。スレッドごとにはプロンプト欄の下の Model / Thinking で替えます。

CLI の設定・MCP・skill

CLI の設定 (user / project / local)、{{backend.primaryInstructionsFile}}、skill、あなたの MCP サーバ、プロジェクトの .mcp.json は、ターミナルで使うときと同じく CLI 自身が読みます。 同じフォルダで開けば、これまでのメモリもそのまま効きます。外部サービスの API キーも CLI の MCP の設定に入れます ({{app.name}} は読みません・持ちません)。

{{app.name}} は加えて、自分の MCP のゲートウェイを必ず CLI に渡します。これを通して AI は Mac 全体の索引の検索・資料の読み出し・ビューアでファイルを開く操作ができます。

設定の「Skills」で、登録されている skill の一覧と中身を見て、ゴミ箱へ移す・新しく作ることができます。

更新

{{app.name}} はエージェント CLI 自身の更新を、何も動いていないときに呼びます (設定 > 更新 > エージェント CLI の自動更新)。

費用の数字は画面に出しません。見たいときは CLI の /cost を使ってください。

Agent CLI

{{app.name}} runs one of two CLIs. {{app.name}} bundles neither; it uses the one you installed. Whether it is installed, its version and its login state are shown under Agent CLI in Settings > About.

  • {{backend.primary}}: logging in (subscription or API key) works the way the CLI does it. {{app.name}} never reads the CLI’s credentials.
  • {{backend.secondary}}: install it with {{backend.secondaryInstall}}. It can use free models and local models through Ollama (ollama pull gpt-oss:20b). Some features, such as thinking levels, rewind and image input, are not available.

You choose which one runs when you create a new thread.

Model and Thinking

The initial values for new threads are under Settings > New Thread. Change them per thread with Model / Thinking below the prompt box.

CLI settings, MCP and skills

The CLI itself reads its settings (user / project / local), {{backend.primaryInstructionsFile}}, skills, your MCP servers and the project’s .mcp.json, exactly as in a terminal. Open the same folder and your existing memory keeps working. API keys for outside services also go into the CLI’s MCP settings ({{app.name}} neither reads nor stores them).

In addition, {{app.name}} always passes its own MCP gateway to the CLI. Through it the AI can search the index of your whole Mac, read documents and open files in the viewer.

Settings > Skills lists your installed skills, shows their content, moves them to the Trash and creates new ones.

Updates

{{app.name}} calls the agent CLI’s own update while nothing is running (Settings > Update > Agent CLI Auto Update).

{{app.name}} does not show cost figures. To see them, use the CLI’s /cost.

困ったときTroubleshooting

キーチェーンの「{{app.dataName}} Safe Storage」の確認が出た

「常に許可」を押します。「拒否」すると暗号化した DB が開けず、{{app.name}} はメモリだけで動きます (終了すると会話が残りません)。

検索に出ないファイルがある

初めての起動では Mac 全体の索引づくりが裏で走ります (数分以上。最初は遅く走り、操作していないと速くなります)。macOS のアクセスの確認が出たら許可します。 入れて最初の 3 日はデスクトップ・書類・ダウンロードを走査しません (設定 > 外部ストレージで今すぐ含められます)。外付けのディスクは既定では含めません。

ログインが切れた

会話の上に知らせが出ます。札の「ログインする」で Terminal にログインの手順を起こし、ログインし終わると止まっていた入力を自動で 1 回送り直します。 設定 > アカウントと使用量 で、切れたのを見つけたら自動で開くようにもできます。

回答が途中で止まった

中断した会話の行に「!」が出て、再開のボタンで続きを頼めます。使用量の上限で止まったときは「解除後に再開」で予約できます。 ネットやモデルにつながらない間は画面下のバーが赤くなります。

コマンドが動かない

/status /help /memory などの対話画面専用のコマンドは使えません。CLI 自身の許可リストにあるものは {{app.name}} の承認に出ません。

ヘルプが表示されない

ヘルプは HTML の拡張機能で表示します。拡張機能ビュー (⌘⇧X) で HTML が有効か確かめてください。

不具合を知らせるとき

設定 > 情報 の「バージョン情報」で コピー を押すと版と環境が入ります。ログのフォルダを開くで、いまのログのファイル (~/Library/Logs/{{app.dataName}}/) を Finder で見せます。

The keychain asks about “{{app.dataName}} Safe Storage”

Click Always Allow. If you deny it, {{app.name}} cannot open its encrypted database and runs in memory only (conversations are lost when you quit).

Some files do not show up in search

On the first launch {{app.name}} builds the index of your whole Mac in the background (several minutes or more; it runs slowly at first and faster while you are not using the Mac). Allow the macOS access prompts if they appear. For the first 3 days after install, Desktop, Documents and Downloads are not scanned (include them now under Settings > External Storage). External disks are not included by default.

The login expired

A notice appears above the conversation. “Log in” on the badge starts the login steps in Terminal, and once you have logged in, the input that was stopped is sent again once, automatically. Under Settings > Account & usage you can have {{app.name}} open the login automatically when it notices.

An answer stopped halfway

The interrupted thread shows “!” on its row, and the resume button asks for the rest. When it stopped at a usage limit, “Resume after limit resets” schedules it. The bottom bar turns red while the network or the model cannot be reached.

A command does not work

Commands that only work in the interactive screen, such as /status /help /memory, are not available. Anything in the CLI’s own allow list never reaches {{app.name}}’s approvals.

Help does not appear

Help is shown by the HTML extension. Check that HTML is enabled in the Extensions view (⌘⇧X).

Reporting a problem

In Settings > About, Copy under the version information copies the version and environment. Show Log Folder shows the current log file (~/Library/Logs/{{app.dataName}}/) in Finder.
