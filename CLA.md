## How to sign

When you open your first pull request, a bot posts a comment with a link to this document. To sign, reply on the pull request with
exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username, the time, and the pull request number are recorded in the repository's `cla-signatures` branch. You only need to
sign once.
